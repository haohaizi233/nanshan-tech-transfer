## 一、项目概况

### 1.1 项目是什么

「南山科转通」是一个基于 **uni-app（Vue 3）** 开发的微信小程序，面向科技成果转化场景，核心功能包括：

| 模块 | 页面 | 说明 |
|------|------|------|
| 首页 | `pages/index/index.vue` | Banner、搜索入口、需求/成果列表 |
| AI 匹配 | `pages/ai-match/ai-match.vue` | AI 对话式匹配（当前为演示版，规则匹配模拟） |
| 我的 | `pages/mine/mine.vue` | 注册/登录/资料管理/我的发布/收藏/意向 |
| 资本对接 | `pages/capital-list/capital-list.vue` | 概念验证平台、投资机构、银行机构列表 |
| 分包页面 | `packageA/` | 搜索、对接详情、发布需求/成果、年费详情、我的列表、AI 评估详情 |

### 1.2 当前项目状态（重要！）

**这是一个前端演示阶段的项目，请务必理解以下几点：**

1. **注册/登录没有后端**：账号密码全部存在用户手机本地（`uni.setStorageSync`），换手机或微信清理缓存后数据会丢失。`common/user.js` 里已加入存储错误处理和「诊断存储」功能（在「我的」页面底部）。
2. **数据以演示数据为主**：`common/config.js` 中 `USE_CAPITAL_DEMO = true`，资本对接等模块读的是本地写死的演示数据，不连后端。
3. **后端已备好但未接入前端**：`tools/api-server/` 是一个 Flask 后端，能提供资本对接数据接口；把 `USE_CAPITAL_DEMO` 改为 `false` 并配置好 `API_BASE` 即可联调。
4. **未在微信公众平台发布**：目前是开发版，只能在微信开发者工具和体验版中运行。

## 三、环境搭建（接手人必做）

### 3.1 软件清单

| 软件 | 用途 | 下载 |
|------|------|------|
| HBuilderX（最新正式版） | 打开和编译小程序源码 | https://www.dcloud.io/hbuilderx.html |
| 微信开发者工具（稳定版） | 运行/调试微信小程序 | https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html |
| Python 3.10+ | 运行后端 API 和爬虫 | https://www.python.org |
| MySQL 8.x | 存储业务数据（可选，演示模式不需要） | https://dev.mysql.com/downloads/installer/ |

### 3.2 前端运行步骤

1. 用 **HBuilderX** 打开 `南山\` 目录（文件 → 打开目录）。
2. 菜单：**运行 → 运行到小程序模拟器 → 微信开发者工具**。
   - 首次运行会提示设置微信开发者工具的安装路径。
   - 编译完成后会自动生成 `南山\unpackage\dist\dev\mp-weixin\` 目录。
3. 打开 **微信开发者工具** → 导入项目 → 选择上面生成的 `mp-weixin` 目录。
4. 填写 AppID：
   - 测试阶段可选「测试号」；
   - 正式使用需登录微信公众平台（mp.weixin.qq.com）→ 开发管理 → 开发设置，获取小程序 AppID，填入 `南山\project.config.json` 的 `"appid"` 字段（该文件已脱敏，内有注释指引）。
5. 在微信开发者工具中点击「编译」即可看到小程序。

> **踩坑提醒**：修改了 `南山\` 里的源码后，必须在 HBuilderX 里**重新运行编译**，微信开发者工具里才会生效。直接改 `unpackage` 目录里的文件是无效操作（重新编译会被覆盖）。

### 3.3 数据库恢复步骤（可选，演示模式可跳过）

1. 安装 MySQL 8.x，记录 root 密码。
2. 创建数据库并导入备份：

```powershell
mysql -u root -p -e "CREATE DATABASE nanshan_capital CHARACTER SET utf8mb4"
mysql -u root -p nanshan_capital < tools\nanshan_capital_backup.sql
```

3. 填写连接配置：`tools\platform-crawler\db_config.json` 和 `tools\szte-crawler\db_config.json`（已脱敏，按文件内 `note` 字段说明填写 user/password/port）。

> 备用方案：如果 SQL 备份不可用，爬虫目录下的 `schema_*.sql`（建表）+ `*_data.json`（数据）也能重建数据。

### 3.4 后端 API 启动步骤（可选，演示模式可跳过）

```powershell
cd tools\api-server
pip install -r requirements.txt
python app.py
```

- 服务监听 **8787** 端口，数据来自第 3.3 步恢复的 MySQL。
- 联调前端：把 `南山\common\config.js` 中 `USE_CAPITAL_DEMO` 改为 `false`，并把 `API_BASE` 改为：
  - 模拟器调试：`http://127.0.0.1:8787`
  - 真机调试：`http://你电脑的局域网IP:8787`（`ipconfig` 可查，手机需与电脑同一 WiFi）

### 3.5 数据库导出 Excel（复用脚本）

```powershell
python tools\export_db_to_excel.py                          # root 无密码时
python tools\export_db_to_excel.py --user root --password 你的密码
```

## 四、关键技术设计（修改代码前必读）

### 4.1 用户体系（本地存储方案）

- 所有用户数据通过 `common\user.js` 管理，存储在小程序本地缓存中：

| 存储 Key | 内容 |
|----------|------|
| `ns_user_accounts` | 账号库（手机号 → 密码/资料） |
| `ns_user_session` | 当前登录手机号 |
| `ns_user_favorites_{手机号}` | 按账号隔离的收藏 |
| `ns_user_intentions` | 对接意向（全局共享） |
| `ns_user_demands` / `ns_user_results` | 发布的需求/成果 |

- **密码是本地明文存储的**（演示方案）。接入正式后端时必须改为：微信 `login` 拿 code → 后端换 openid → 服务端下发 token。
- 已知风险：微信清理缓存会丢数据。`user.js` 中已加入 try-catch，读写失败时会给出明确提示。

### 4.2 对接意向流程

意向状态机（`common\user.js`）：

```
pending（待定）→ accepted（接收方同意）→ success（发起方最终确认）
     ↓                 ↓
  rejected          rejected
```

- 需求类内容对接成功后锁定，同目标的其他意向自动拒绝（`autoRejectCompetitors`）。
- 成果类内容允许对接多个需求。
- 身份约束：需求方只能对接成果，供给方只能对接需求（`canDockContentType`）。

### 4.3 演示模式开关

`common\config.js`：

```javascript
export const USE_CAPITAL_DEMO = true   // true=本地演示数据；false=请求 API_BASE
export const API_BASE = 'http://127.0.0.1:8787'
```

`capital.js` 中所有 `fetch*` 函数都会先判断这个开关。

### 4.4 手机屏幕适配

- 全部页面已做 iPhone 刘海屏/底部横条适配：`padding-bottom: calc(XXrpx + env(safe-area-inset-bottom))`。
- 全局变量在 `uni.scss`：`$safe-inset-bottom` / `$safe-inset-top`。
- **新增页面时底部必须加安全区适配**，否则 iPhone X 及以上机型底部按钮会被遮挡。
- 参考范例：`pages/ai-match/ai-match.vue` 的 `.composer`。

### 4.5 开发规范

- 遵守 `.cursorrules` 中的约定：Vue 单文件组件（template → script → style）、只用 uni-app 跨端 API（禁止直接调 `wx.*`）、路由统一在 `pages.json` 管理、组件 PascalCase、页面 kebab-case。
- 需要平台差异化代码时用条件编译：`// #ifdef MP-WEIXIN ... // #endif`。

## 六、关于"嵌入其他小程序"的说明

业务上提到本小程序后续**不对公众上线，仅嵌入到其他小程序中使用**。需要明确：

1. 小程序间跳转走 `wx.navigateToMiniProgram`，**前提是本小程序已在微信公众平台注册并发布过版本**（至少体验版，跳转时用 `envVersion: 'trial'`）——不存在"完全不发布"的嵌入方式。
2. 本小程序的 AppID 必须填入 `manifest.json` 的 `mp-weixin.appid`。
3. 如果是"本小程序跳转别的小程序"，在 `common\external-miniprogram.js` 填入对方 AppID，并在 `manifest.json` 的 `navigateToMiniProgramAppIdList` 中登记。
4. 上线前注意：`manifest.json` 中 `urlCheck: false` 仅用于开发；正式版必须在公众平台配置服务器合法域名（且必须是 HTTPS）。

## 八、常见问题（FAQ）

**Q1：改了源码，微信开发者工具里没变化？**
A：没有在 HBuilderX 重新编译。运行 → 运行到小程序模拟器。必要时先「运行 → 清除缓存」。

**Q2：真机上点「确认对接」等底部按钮没反应？**
A：检查该页面是否漏了 `env(safe-area-inset-bottom)` 适配（见 4.4）。

**Q3：注册成功但重新进入后账号没了？**
A：微信清理了本地缓存。这是本地存储方案的固有限制，根治方案是接后端（见七-P0）。

**Q4：真机调试连不上后端？**
A：① 确认电脑和手机同一 WiFi；② `API_BASE` 改成电脑局域网 IP 而非 127.0.0.1；③ 确认 `python app.py` 正在运行；④ 关闭电脑防火墙或放行 8787 端口。

**Q5：Workbench 双击数据库连接打不开？**
A：MySQL 服务没启动。原开发机的 MySQL 未注册为 Windows 服务，需手动启动；新机器建议安装时用官方 Installer 并勾选「作为 Windows 服务运行」。

**Q6：演示数据和真实数据怎么切换？**
A：`common\config.js` 的 `USE_CAPITAL_DEMO` 开关（见 4.3）。
