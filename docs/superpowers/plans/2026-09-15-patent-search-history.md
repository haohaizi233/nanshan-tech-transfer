# 专利检索历史 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist each user's latest submitted patent searches and make them one-tap, mode-aware repeat searches in the mini-program and H5 UI.

**Architecture:** Add a focused `modules/patent/history.py` data service plus two authenticated routes under the existing patent router. The frontend consumes typed history wrappers in the existing patent API file, then renders at most two visual lines of recent-query tags in `patent-list.vue`; click reuses the existing `onSearch` pathway.

**Tech Stack:** FastAPI, PostgreSQL/psycopg2, uni-app Vue 2, Node built-in test runner, Python integration scripts.

**Spec:** `docs/superpowers/specs/2026-09-15-patent-search-history-design.md`

## Global Constraints

- Persist only explicit Search/keyboard-confirm submissions, never input keystrokes.
- Isolate data by authenticated `identity.userId`; clients never send a user ID.
- Allow only `keyword` and `assignee` modes, normalize whitespace, and allow at most 128 characters.
- Keep at most 10 deduplicated records per user and mode, ordered by latest use.
- History UI shows at most two lines; failed history operations never block patent searching.
- Do not add clear-history, single-delete, anonymous history, or a dependency.

```sql
CREATE TABLE IF NOT EXISTS public.patent_search_history (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES public.app_user(id) ON UPDATE CASCADE ON DELETE CASCADE,
    search_mode VARCHAR(16) NOT NULL CHECK (search_mode IN ('keyword', 'assignee')),
    keyword VARCHAR(128) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE (user_id, search_mode, keyword)
);
CREATE INDEX IF NOT EXISTS idx_patent_search_history_recent
    ON public.patent_search_history(user_id, search_mode, updated_at DESC);
```

- [ ] **Step 4: Implement the service and trim overflow in its write transaction**

```python
VALID_MODES = ('keyword', 'assignee')

def record_history(user_id, mode, keyword):
    mode, keyword = _validate(mode, keyword)
    with get_cursor(commit=True) as cur:
        cur.execute("""
            INSERT INTO patent_search_history (user_id, search_mode, keyword)
            VALUES (%s, %s, %s)
            ON CONFLICT (user_id, search_mode, keyword)
            DO UPDATE SET updated_at = CURRENT_TIMESTAMP
            RETURNING keyword, search_mode, updated_at
        """, (user_id, mode, keyword))
        row = cur.fetchone()
        cur.execute("""
            DELETE FROM patent_search_history WHERE id IN (
              SELECT id FROM patent_search_history
              WHERE user_id=%s AND search_mode=%s
              ORDER BY updated_at DESC, id DESC OFFSET 10
            )
        """, (user_id, mode))
    return _item(row)
```
